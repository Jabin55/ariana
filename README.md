# 정치쌤 챗봇 · 실시간 수업

> 🎥 **실시간 온라인 수업 플랫폼**은 아래 [실시간 수업](#실시간-수업-live) 부분을 보세요.

고등학교 **정치** 과목(2022 개정 교육과정)을 공부하는 학생이 질문하고 답변을 받는 웹 챗봇입니다. Claude API를 사용합니다.

- **개념 질의응답**: 교과 개념을 학생 눈높이로 설명하고 헷갈리기 쉬운 점을 짚어 줍니다.
- **문제 풀이·퀴즈**: "문제 내 줘"라고 하면 OX·5지선다·서술형 문제를 내고, 학생 답을 채점·해설합니다.
- **정치적 중립**: 특정 정당·후보를 지지하지 않고, 쟁점은 여러 입장을 균형 있게 소개합니다.

## 실행 방법

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...      # Anthropic 콘솔에서 발급
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

브라우저에서 http://localhost:8000 을 열면 됩니다. 같은 네트워크의 학생들은 `http://<이 컴퓨터 IP>:8000` 으로 접속할 수 있습니다.

## 인터넷에 배포하기 (Render)

이 저장소에는 [Render](https://render.com) 배포 설정(`render.yaml`)이 들어 있습니다.

1. Render에 GitHub 계정으로 가입·로그인합니다.
2. **New → Blueprint** 를 누르고 `jabin55/ariana` 저장소를 선택합니다.
3. `ANTHROPIC_API_KEY` 입력란에 API 키를 넣고 **Apply** 를 누릅니다.
4. 몇 분 뒤 `https://politics-chatbot-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 학생들에게 알려 주면 됩니다.

> 이 설정 파일(`render.yaml`)은 사이트를 **두 개** 만듭니다. 정치쌤 챗봇(`politics-chatbot-….onrender.com`)과
> 실시간 수업(`live-class-….onrender.com`, 첫 주소가 바로 수업 화면)입니다. 실시간 수업 사이트에 넣을 값은 아래 [실시간 수업](#실시간-수업-live) 부분을 보세요.
> 주소 앞부분은 서비스 이름으로 정해지니, 원하는 이름이 있으면 `render.yaml` 의 `name` 을 바꾸거나 Render 화면에서 바꾸면 됩니다.

이후 GitHub 저장소에 코드를 올리면 Render가 자동으로 다시 배포합니다.
무료 요금제는 한동안 접속이 없으면 잠들었다가, 다음 접속 때 깨어나느라 첫 화면이 30초~1분 정도 늦게 뜰 수 있습니다.

## 참고

- 대화 기록은 학생 브라우저에만 있고 서버에 저장하지 않습니다. 새로고침하면 사라집니다.
- 정책상 답변이 거절되면 서버에서 다른 모델로 자동 재시도합니다(`fallbacks: "default"`).
- 화면의 마크다운 렌더링 라이브러리(marked, DOMPurify)는 `static/vendor/`에 포함되어 있어 학교망에서 CDN이 막혀도 동작합니다.
- 시스템 프롬프트는 프롬프트 캐싱을 적용해 반복 요청 비용을 줄입니다.
- 학생들에게 공개 배포하려면 로그인이나 접속 제한, 사용량 제한(rate limit)을 추가하는 것을 권장합니다. 현재는 누구나 접속하면 API 비용이 발생합니다.

## 실시간 수업 (`/live`)

같은 서버에 들어 있는 **화상 수업 플랫폼**입니다. 중·고등학생 한 반(~35명) 규모를 기준으로 만들었고,
**학교에서 받은 구글 계정으로만 로그인**합니다.

| 기능 | 내용 |
|---|---|
| **강좌·수강신청** | 학기 초 선생님이 강좌(강의명·강사명·거점학교명·강의기간)를 개설하고 학생이 수강신청(거점학교 공동교육과정처럼 **다른 학교 학생도** 가능, 강의기간이 지나면 신규 신청 마감) → 선생님이 승인. 승인된 학생은 수업 때 **코드 없이** 첫 화면에서 바로 입장, 승인 안 된 학생은 코드를 알아도 입장 불가. 출결의 '미접속'도 수강생 기준 |
| 로그인 | 학교 구글 계정(정한 도메인)만 로그인. 처음 한 번 학교·학년·반·번호·이름 입력 → 학번 자동(예: 20315). 비밀번호를 저장하지 않음 |
| 화상·음성 | 선생님 카메라·화면 공유를 크게, 학생들은 작은 타일로. 휴대폰·크롬북에서도 동작 |
| 수업 진행 | OX·객관식·투표·주관식을 보내면 응답이 실시간으로 모이고, 원할 때 결과 공개 |
| 채팅·질문 | 전체 채팅(끄고 켜기), **선생님에게만 보이는 질문**과 1:1 답변, 질문을 공지로 띄우기. **질문답변은 영구 보관**: 선생님은 출결 기록에서 수업별로 조회·CSV, 학생은 첫 화면에서 지난 질문답변 확인 |
| 수업 관리 | 손 들기, 모두 음소거·카메라 끄기, **마이크 잠금 + 발언권 주기**(화상 서버가 강제), 내보내기(그 수업에 다시 못 들어옴) |
| **데이터 절약 모드** | 기본으로 켜짐. 전체 교실에서는 학생 카메라 꺼짐(모둠 활동·발언권 때만), 영상 화질 상한. 학생이 받는 데이터가 약 1/3로 줄어 화상 서버 비용과 학생 휴대폰 데이터를 아낌 |
| AI 조교 | 학생 화면 옆에 정치쌤 챗봇. 퀴즈 중에는 선생님이 끌 수 있음 |
| **모둠(소그룹)** | 무작위 배정·직접 옮기기, 타이머, 모든 모둠 채팅에 글 공지 |
| **모둠 관찰** | 모든 모둠 영상을 한 화면에, 말하는 모둠 표시. 🎧 원하는 모둠 소리만 골라 듣기(여러 개 동시 가능), 🎤 한 모둠에 들어가 말하기, 🙋 학생 호출 표시 |
| **모든 모둠에 말하기** | 📢 버튼 하나로 모든 모둠에 동시에 선생님 마이크를 켜서 음성 공지 |
| **수업 후 채점** | 출결 기록 화면에서 수업별 퀴즈·활동 답안 확인. 객관식·OX는 자동 채점, 주관식은 점수·피드백 입력, 배점 조정, 학생별 총점, 점수 CSV. **공개**를 켜면 학생이 첫 화면에서 자기 점수·피드백 확인 |
| **출결 기록** | 날짜별 수업 목록 → 학생별 첫 접속·마지막 종료(사유)·접속 시간·**재입장 횟수**·**중간 이탈 시간**, 들어오고 나간 기록 전부. 대상 학급을 정하면 **미접속 학생**도 표시. 출결 요약·입퇴장 전체 기록·퀴즈 결과 CSV(엑셀) |

학생 화면에는 선생님이 그 모둠을 듣고 있을 때 "🎧 선생님이 듣고 있어요"가 표시됩니다. 학생들이 모르게 엿듣지 않도록 일부러 넣은 표시입니다.

### 쓰는 법

**학기 초 (한 번)**
1. 선생님: `https://내주소/live` → 구글 로그인 → (처음 한 번) 이름·학교 → **강좌·수강생** 탭에서 강좌를 개설합니다. **강의명·강사명·거점학교명·강의기간**(필수)과 설명(선택)을 적고, 나중에 **정보 수정**으로 고칠 수 있습니다.
2. 학생: 같은 주소 → 학교 구글 계정으로 로그인 → (처음 한 번) 학교·학년·반·번호·이름 → 첫 화면 **수강신청**에서 신청.
3. 선생님: **강좌·수강생** 탭 → **수강생 관리**에서 승인(또는 **모두 승인**)·거절. 승인 대기 수가 탭에 빨간 숫자로 보입니다.

**수업 때마다**
1. 선생님: **수업** 탭에서 강좌를 고르고 **수업 열기**.
2. 학생: 첫 화면 **지금 들어갈 수 있는 수업**에 수업이 뜨면 **입장하기** (코드 입력 없음, 15초마다 자동으로 새로 고침).
   승인되지 않은 학생은 수업이 보이지 않고, 코드를 알아도 들어올 수 없습니다.
3. 모둠 활동: 오른쪽 **모둠** 탭 → 모둠 수 → **무작위 배정** → **모둠 활동 시작**.
   가운데에 모든 모둠이 보이고, 카드마다 **🔇 듣기 / 🎤 들어가서 말하기**, 위쪽 **📢 모든 모둠에 말하기**.
4. 수업이 끝나면 첫 화면의 **출결 기록** 탭(수업 화면 위 **출결 기록** 버튼)에서 출결·질문답변·채점을 봅니다.

특강·보충수업·상담처럼 강좌와 상관없이 한 번 여는 수업은 강좌 대신 **특강·모임**을 고르면 6자리 수업 코드로 들어옵니다(코드를 아는 학생이면 누구나 입장).
학기가 끝나면 강좌를 **보관**하세요(수강신청이 닫히고 기록은 남습니다).

### 운영 비용

**한 달 5회 × 4시간, 한 반 35명 기준**이면 화상 사용량이 약 **43,000 참가자·분**(36명 × 240분 × 5회)이라 무료 한도(5,000)를 크게 넘습니다.
그래서 **화상만 유료**, 나머지는 무료로 운영하는 구성을 권장합니다.

| 역할 | 서비스 | 요금 (2026년 10월 확인, 바뀔 수 있음) |
|---|---|---|
| 웹 서버 | Render 무료 웹 서비스 | 무료 (월 750시간). 안정성이 걱정되면 Starter 월 $7 |
| 데이터베이스(회원·출결) | [Neon](https://neon.com) 무료 PostgreSQL | 무료 (1GB, 월 100 CU-시간, 기한 없음) |
| 화상·음성 | **직접 운영 (Hetzner, 추천)** — [설치 안내](deploy/livekit/README.md) | 월 약 €6 (한 반) ~ €30~60 (학교 전체) |
| 화상·음성 (대안) | [LiveKit Cloud](https://livekit.io/pricing) **Ship** | 월 $50: 15만 참가자·분, 내려받는 데이터 250GB 포함. 넘으면 GB당 $0.12 |

- 참가자·분은 Ship 포함량(15만) 안에 넉넉히 들어갑니다.
- 데이터 절약 모드(기본)를 켜 두면 35명 × 월 5회 × 4시간에 약 100~180GB라 포함량(250GB) 안에 들어갑니다. 예상: **월 $50 (약 7만 원)**.
  절약 모드를 끄면 250GB를 넘을 수 있어요(넘는 만큼 GB당 $0.12). 첫 달은 LiveKit 대시보드에서 사용량을 확인해 보세요.
- 더 싸게: 서울 지역 가상 서버에 LiveKit을 직접 설치하면 월 3~4만 원 선이지만(아래), 설치·관리를 직접 해야 하고 수업 중 문제가 생기면 스스로 고쳐야 합니다.
- **Render의 무료 PostgreSQL은 쓰지 마세요.** 30일 뒤 만료되고 14일 뒤 데이터가 지워집니다.
- 화상은 LiveKit이 따로 중계하므로, Render 서버가 잠깐 재시작돼도 영상은 끊기지 않습니다. 수업과 출결은 DB에 있어 같은 코드로 이어지고 학생 화면은 자동으로 다시 연결됩니다(진행 중이던 채팅·질문은 사라짐).
- 학교 청구용으로는 LiveKit(해외 결제, 달러)·Render 영수증이 이메일로 옵니다.

### 설정 순서

**1) 구글 로그인 (Google Cloud 콘솔, 무료)**
1. https://console.cloud.google.com 에서 프로젝트를 만들고 **API 및 서비스 → OAuth 동의 화면**을 설정합니다. 사용자 유형은 **외부**, 범위는 기본(이메일·프로필)만 쓰면 되고, 설정 후 **앱 게시(프로덕션)** 를 누릅니다. 기본 범위만 쓰면 별도 심사가 필요 없습니다.
2. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션**. **승인된 자바스크립트 원본**에 `https://내서비스.onrender.com` 을 넣습니다.
3. 만들어진 클라이언트 ID를 `GOOGLE_CLIENT_ID` 에 넣습니다.

**2) 학교 구글 관리자에게 앱 허용 요청 (중요)**
Google Workspace for Education은 **만 18세 미만 학생이 관리자가 허용하지 않은 외부 앱에 로그인하는 것을 막습니다.**
학교(또는 교육청) 구글 관리자에게 위 클라이언트 ID를 알려 주고 **관리 콘솔 → 보안 → API 제어 → 앱 액세스 제어**에서
이 앱을 **신뢰함(Trusted)** 으로 설정해 달라고 요청하세요. 이 설정이 없으면 학생은 로그인할 때 "관리자에게 액세스 요청" 화면을 보게 됩니다.

**3) Neon 데이터베이스** — 가입 → 프로젝트 만들기(지역: **AWS Europe Central (Frankfurt)** — 개인정보 해외 이전 때문에 EU로) → 연결 문자열(`postgresql://...`)을 `DATABASE_URL` 에.

**4) LiveKit** — https://cloud.livekit.io 가입 → 프로젝트 → Settings → Keys 에서 URL·키·시크릿을 `LIVEKIT_*` 에. 시험은 무료(Build)로 하고, 정규 수업 전에 **Billing에서 Ship 요금제로 올리세요**(무료 한도를 넘으면 그 달은 화상 접속이 막힙니다).

**5) Render 환경 변수** — Blueprint로 배포하면 생기는 **`live-class`** 서비스에 넣습니다 (정치쌤 챗봇과 별개의 사이트).

| 변수 | 설명 |
|---|---|
| `GOOGLE_CLIENT_ID` | 1)에서 만든 OAuth 클라이언트 ID |
| `ALLOWED_DOMAINS` | 학생 구글 계정 도메인 (예: `s.school.kr`, 쉼표로 여러 개). 비우면 **아무 구글 계정이나** 학생으로 로그인되니 꼭 넣으세요 |
| `TEACHER_EMAILS` | 선생님 계정 이메일 (쉼표로 여러 개). 여기 있는 계정만 수업을 열고 출결을 봅니다 |
| `SCHOOLS` | 학생이 고를 학교 이름 목록 (쉼표). 비우면 직접 입력 |
| `DATABASE_URL` | 3)의 Neon 주소 |
| `SECRET_KEY` | 로그인 쿠키 서명용. `render.yaml` 로 배포하면 자동 생성 |
| `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` | 4)의 값 |

### 화상 서버를 직접 운영하기 (추천: 연 10만 원대)

**[deploy/livekit/README.md](deploy/livekit/README.md)** 를 따라 Hetzner 해외 서버(월 약 €6, 트래픽 20TB 포함)에 설치하면
LiveKit Cloud 요금 없이 운영할 수 있습니다. 서버를 만들 때 [`cloud-init.yaml`](deploy/livekit/cloud-init.yaml) 을 붙여 넣으면 설치가 자동으로 끝나고,
HTTPS 인증서·보안 업데이트·재시작이 모두 자동이라 평소 관리할 일이 없습니다. 학교 와이파이처럼 UDP가 막힌 곳을 위한 우회 경로(TURN, 443 포트)도 함께 설정됩니다.

### 개인정보 관련 확인할 점

**어디에 무엇이 가나요**

| 서비스 | 위치 | 다루는 정보 |
|---|---|---|
| 수업 사이트 (Render `live-class`) | **독일 프랑크푸르트** (`render.yaml` 에 지정) | 로그인, 수업 진행 |
| 데이터베이스 (Neon) | **독일 프랑크푸르트로 만들 것** (AWS Europe Central) | 이메일·이름·학번, 출결, 질문답변, 퀴즈 답·점수·피드백 |
| 화상 서버 (Hetzner) | **독일 또는 핀란드** | 영상·음성을 실시간으로 전달만 함(저장 안 함), 화면 이름(학번+이름) |
| AI 조교 (Anthropic) | 미국 | 학생이 AI 조교에 입력한 질문 내용 (이름·학번은 보내지 않음) |
| 구글 로그인 | — | 학교가 이미 쓰는 구글 계정으로 본인 확인만 함 |

- **해외 이전에 해당합니다.** 한국 밖 서버에 학생 개인정보를 보관·처리하기 때문이에요(개인정보 보호법 제28조의8).
- **EU라면 별도 동의 없이 가능합니다.** 2025년 9월 개인정보보호위원회가 EU 체계를 국내와 실질적으로 동등하다고 인정해서, EU·EEA(독일·핀란드 포함)로는 별도 동의 없이 이전할 수 있어요. 그래서 위 표처럼 사이트·데이터베이스·화상 서버를 모두 EU에 두는 것을 권장합니다. 다만 **개인정보 처리방침(또는 가정통신문)에 이전 국가·항목·업체·보유 기간을 알리는 것**은 필요해요.
- **AI 조교는 미국으로 갑니다.** 학생이 질문에 개인정보를 적으면 미국으로 넘어가요. 학생에게 "AI 조교에 이름·연락처를 적지 말 것"을 안내하거나, 선생님 화면에서 AI 조교를 꺼 두세요.
- **만 14세 미만 학생은 법정대리인 동의가 필요할 수 있습니다** (중1, 중2 일부, 개인정보 보호법 제22조의2). 학교 차원의 수집·이용 동의 범위에 들어가는지 학교 개인정보 담당자와 먼저 확인하세요.
- **학습지원 소프트웨어 심의:** 교육부가 2025년 12월 발표한 기준에 따라, 정규 수업에서 학생 개인정보를 처리하는 소프트웨어는 필수기준(최소 수집, 안전조치, 열람·정정·삭제 절차, 만 14세 미만 보호, 위탁 등) 체크리스트를 확인하고 **학교운영위원회 심의**를 거쳐야 합니다. 이 플랫폼도 대상이니 학교 담당자와 함께 준비하세요.
- 저장하지 않는 것: 영상·음성 녹화, 전체·모둠 채팅, AI 조교 대화.

### 알아 둘 점

- Render 무료 서버는 잠들어 있을 수 있으니 수업 1~2분 전에 페이지를 열어 깨워 두세요. 수업 도중 재배포는 피하세요.
- 마이크 잠금과 데이터 절약 모드의 카메라 제한은 화상 서버가 강제합니다. '모두 음소거'·'카메라 끄기' 버튼은 학생 화면이 따르는 방식이라 학생이 다시 켤 수 있으니, 계속 말해야 하면 마이크 잠금을 쓰세요. 문제 학생은 **✕ 내보내기**로 화상 연결까지 끊을 수 있습니다.
- 출결 기록의 '접속 시간'은 수업 화면을 열어 둔 시간입니다. 화면 앞에 실제로 있었는지는 알 수 없습니다.
- 모둠 관찰 중 여러 모둠 소리를 켜면 섞여 들리니 이어폰을 쓰세요.

# 로컬 시험: livekit-server --dev 실행 후 (DEV_LOGIN=1 은 구글 없이 이메일만으로 로그인하는 개발용. 배포 서버에서는 절대 켜지 마세요)
