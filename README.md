# 정치쌤 챗봇 · 실시간 수업

> 🎥 **실시간 온라인 수업 플랫폼**은 아래 [실시간 수업](#실시간-수업-live) 부분을 보세요.

고등학교 **정치** 과목(2022 개정 교육과정)을 공부하는 학생이 질문하고 답변을 받는 웹 챗봇입니다. Claude API를 사용합니다.

- **개념 질의응답**: 교과 개념을 학생 눈높이로 설명하고 헷갈리기 쉬운 점을 짚어 줍니다.
- **문제 풀이·퀴즈**: "문제 내 줘"라고 하면 OX·5지선다·서술형 문제를 내고, 학생 답을 채점·해설합니다.
- **정치적 중립**: 특정 정당·후보를 지지하지 않고, 쟁점은 여러 입장을 균형 있게 소개합니다.

## 실행 방법

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...      # Anthropic 콘솔에서 발급
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

브라우저에서 http://localhost:8000 을 열면 됩니다. 같은 네트워크의 학생들은 `http://<이 컴퓨터 IP>:8000` 으로 접속할 수 있습니다.

## 인터넷에 배포하기 (Render)

이 저장소에는 [Render](https://render.com) 배포 설정(`render.yaml`)이 들어 있습니다.

1. Render에 GitHub 계정으로 가입·로그인합니다.
2. **New → Blueprint** 를 누르고 `jabin55/ariana` 저장소를 선택합니다.
3. `ANTHROPIC_API_KEY` 입력란에 API 키를 넣고 **Apply** 를 누릅니다.
4. 몇 분 뒤 `https://politics-chatbot-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 학생들에게 알려 주면 됩니다.

이후 GitHub 저장소에 코드를 올리면 Render가 자동으로 다시 배포합니다.
무료 요금제는 한동안 접속이 없으면 잠들었다가, 다음 접속 때 깨어나느라 첫 화면이 30초~1분 정도 늦게 뜰 수 있습니다.

## 참고

- 대화 기록은 학생 브라우저에만 있고 서버에 저장하지 않습니다. 새로고침하면 사라집니다.
- 정책상 답변이 거절되면 서버에서 다른 모델로 자동 재시도합니다(`fallbacks: "default"`).
- 화면의 마크다운 렌더링 라이브러리(marked, DOMPurify)는 `static/vendor/`에 포함되어 있어 학교망에서 CDN이 막혀도 동작합니다.
- 시스템 프롬프트는 프롬프트 캐싱을 적용해 반복 요청 비용을 줄입니다.
- 학생들에게 공개 배포하려면 로그인이나 접속 제한, 사용량 제한(rate limit)을 추가하는 것을 권장합니다. 현재는 누구나 접속하면 API 비용이 발생합니다.

## 실시간 수업 (`/live`)

같은 서버에 들어 있는 **화상 수업 플랫폼**입니다. 한 반(~35명) 규모를 기준으로 만들었습니다.

| 기능 | 내용 |
|---|---|
| 화상·음성 | 선생님 카메라·화면 공유를 크게, 학생들은 작은 타일로. 휴대폰·크롬북에서도 동작 |
| 수업 진행 | OX·객관식·투표·주관식을 보내면 응답이 실시간으로 모이고, 원할 때 결과 공개. 결과는 CSV(엑셀)로 내려받기 |
| 채팅·질문 | 전체 채팅(선생님이 끄고 켤 수 있음), **선생님에게만 보이는 질문**과 1:1 답장, 질문을 공지로 띄우기 |
| 수업 관리 | 손 들기, 모두 음소거·카메라 끄기, **마이크 잠금 + 발언권 주기**, 내보내기 |
| AI 조교 | 학생 화면 옆에 정치쌤 챗봇. 시험·퀴즈 중에는 선생님이 끌 수 있음 |
| **모둠(소그룹)** | 무작위 배정·직접 옮기기, 타이머, 모든 모둠에 공지 |
| **모둠 관찰** | 모든 모둠 영상을 한 화면에 보고, 누가 말하고 있는지 표시. 🎧 버튼으로 **원하는 모둠 소리만 골라 켜고 끄기**(여러 모둠 동시 가능), 🎤 버튼으로 그 모둠에 들어가 말하기, 🙋 학생의 선생님 호출 표시 |

학생 화면에는 선생님이 그 모둠을 듣고 있을 때 "🎧 선생님이 듣고 있어요"가 표시됩니다. 학생들이 모르게 엿듣지 않도록 일부러 넣은 표시입니다.

### 쓰는 법

1. 선생님: `https://내주소/live` → 수업 이름과 **선생님 비밀번호** 입력 → **새 수업 열기**
2. 화면 위의 **참여 링크 복사**로 학생들에게 링크(또는 6자리 코드)를 보냅니다.
3. 학생: 링크를 열고 이름을 적고 입장. 카메라·마이크 권한을 물으면 **허용**.
4. 모둠 활동: 오른쪽 **모둠** 탭 → 모둠 수 입력 → **무작위 배정** → (필요하면 학생 옮기기) → **모둠 활동 시작**.
   가운데에 모든 모둠이 보이고, 각 모둠 카드의 **🔇 듣기 / 🎤 들어가서 말하기** 로 관찰합니다. 끝나면 **모두 전체 교실로 돌아오기**.

### 설정 (환경 변수)

| 변수 | 설명 |
|---|---|
| `TEACHER_PASSWORD` | 수업을 만들 때 쓰는 선생님 비밀번호. 없으면 수업을 만들 수 없습니다. |
| `LIVEKIT_URL` | 화상 서버 주소 (`wss://...`) |
| `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` | 화상 서버 키 |

LiveKit 값을 비워 두면 영상 없이 퀴즈·채팅·질문·모둠 배정만 동작합니다.

### 화상 서버(LiveKit) 준비

영상·음성은 오픈소스 화상 서버 [LiveKit](https://livekit.io)이 중계합니다. 두 가지 방법이 있습니다.

**A. LiveKit Cloud (가장 쉬움, 먼저 이걸로 시작 권장)**

1. https://cloud.livekit.io 가입 → 프로젝트 만들기 (지역은 가까운 아시아 쪽)
2. **Settings → Keys** 에서 키를 만들고 `URL`(`wss://…livekit.cloud`), `API Key`, `API Secret`을 Render 환경 변수에 넣습니다.
3. 무료 요금제는 한 달 **5,000 참가자·분**이 한도입니다. 36명이 50분 수업하면 약 1,800분이라 **한 달 2~3회 수업**이면 무료로 충분하고, 넘으면 그 달은 접속이 막힙니다. 정기 수업에 쓰려면 유료 요금제(월 $50부터)나 B를 고려하세요. 요금은 바뀔 수 있으니 [가격 페이지](https://livekit.io/pricing)에서 확인하세요.

**B. 직접 서버 운영 (매주 여러 번 수업할 때 저렴)**

서울 리전 가상 서버(예: AWS Lightsail, Vultr, 네이버 클라우드 등, 2~4코어·4GB, 월 2~4만 원 선)에 LiveKit을 설치합니다.
도메인이 하나 필요하고, [공식 설치 안내](https://docs.livekit.io/home/self-hosting/vm/)의 설정 생성기(`docker run --rm -it -v$PWD:/output livekit/generate`)를 쓰면 HTTPS·TURN 설정까지 만들어 줍니다.
학교망이 UDP를 막는 경우가 많으니 **TURN(TLS 443)을 꼭 켜 두세요.** 생성된 키를 위 환경 변수에 넣으면 끝입니다.

### 알아 둘 점

- 수업 상태(퀴즈 결과·채팅·질문)는 서버 메모리에만 있습니다. 서버가 다시 시작되거나 **수업 종료**를 누르면 사라지므로, 필요한 퀴즈 결과는 **퀴즈·투표 탭 → 결과 내려받기**로 받아 두세요.
- Render 무료 요금제는 한동안 접속이 없으면 잠듭니다. 수업 1~2분 전에 페이지를 열어 깨워 두세요. 수업 도중 재배포하면 수업이 끊깁니다.
- 학생이 새로고침하거나 잠깐 끊겨도 같은 사람으로 다시 들어옵니다(브라우저에 입장 정보 저장).
- 학생 마이크 잠금·음소거는 학생 화면이 따르는 방식이라, 기술적으로 아주 능숙한 학생은 우회할 수 있습니다. 문제 학생은 **✕ 내보내기**로 화상 연결까지 끊을 수 있습니다.
- 수업 코드만 알면 누구나 입장할 수 있으니 코드는 학생들에게만 알려 주세요.
- 모둠 관찰 중 여러 모둠 소리를 켜면 섞여 들리니 이어폰을 쓰세요.

### 개발

```bash
pip install -r requirements.txt pytest httpx
python -m pytest tests          # 수업 서버 테스트
# 화상까지 로컬에서 시험: livekit-server --dev 실행 후
LIVEKIT_URL=ws://localhost:7880 LIVEKIT_API_KEY=devkey LIVEKIT_API_SECRET=secret TEACHER_PASSWORD=pw \
  uvicorn app.main:app --reload
```

| 파일 | 역할 |
|---|---|
| `app/classroom.py` | 수업 서버: 입장권 발급, WebSocket 상태 동기화, 퀴즈·모둠 로직 |
| `static/live/` | 입장(`index.html`), 학생(`student.*`), 선생님(`teacher.*`) 화면과 공통 코드 |
| `static/vendor/livekit-client-*.js` | LiveKit 브라우저 SDK (CDN이 막힌 학교망 대비 포함) |
