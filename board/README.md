# 질문 게시판 (무료 Padlet 대체)

학생이 질문을 올리면 **Gemini AI가 자동으로 답변 댓글**을 달아 주는 게시판입니다.
구글 시트 + Google Apps Script로 돌아가서 서버나 유료 요금제가 필요 없습니다.

- 질문 카드가 Padlet처럼 벽에 붙고, 10초마다 새 글이 자동으로 보입니다.
- 질문마다 AI 답변이 댓글로 달리고, 다른 학생도 댓글을 달 수 있습니다.
- 댓글을 달면 AI가 질문과 앞의 대화를 읽고 이어서 답합니다 (끄려면 스크립트 속성 `AI_REPLY_TO_COMMENTS` 를 `false` 로).
- 모든 글과 댓글은 구글 시트(`Posts`, `Comments` 탭)에 쌓입니다. 부적절한 글은 시트에서 그 줄을 지우면 사라집니다.

## 파일

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 쪽 코드. 시트 저장, Gemini 호출 |
| `Index.html` | 게시판 화면 |
| `Teacher.html` | 선생님 전용 학생 분석 화면 (과목·대단원·역량·인지적 수준 막대그래프) |
| `appsscript.json` | 프로젝트 설정 (clasp를 쓸 때만 필요) |

## 설치 (10분 정도)

### 1. Gemini API 키 받기 (무료)

1. https://aistudio.google.com/apikey 에 구글 계정으로 로그인합니다.
2. **API 키 만들기(Create API key)** 를 누르고, 만들어진 키(`AIza...`로 시작)를 복사해 둡니다.
3. 키는 비밀번호처럼 다루세요. 학생에게 보여 주거나 코드에 직접 적지 마세요.

> 무료 등급은 분당·하루 호출 수에 제한이 있고, Google이 무료 등급 입력 내용을 서비스 개선에 쓸 수 있습니다. 학생들에게 개인정보는 적지 않도록 안내해 주세요.

### 2. 구글 시트와 스크립트 만들기

1. https://sheets.new 로 새 구글 시트를 만들고 이름을 붙입니다 (예: "질문 게시판").
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣습니다.
4. 왼쪽 **파일 옆 +** → **HTML** 을 눌러 이름을 `Index` 로 만들고(`.html`은 자동으로 붙음), `Index.html` 내용을 붙여 넣습니다.
   같은 방법으로 `Teacher` HTML 파일도 만들고 `Teacher.html` 내용을 붙여 넣습니다.
5. 💾 저장합니다.

### 3. API 키 넣기

1. Apps Script 왼쪽의 ⚙️ **프로젝트 설정** 을 엽니다.
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가** 를 누릅니다.
3. 속성 이름에 `GEMINI_API_KEY`, 값에 1단계에서 복사한 키를 넣고 **저장** 합니다.

원하면 아래 속성도 추가할 수 있습니다 (안 넣어도 됩니다).

| 속성 | 설명 | 기본값 |
|---|---|---|
| `BOARD_TITLE` | 게시판 제목 | 질문 게시판 |
| `GEMINI_MODEL` | 사용할 Gemini 모델 | gemini-3.8-flash |
| `AI_NAME` | AI 답글에 표시할 이름 | AI 튜터 |
| `CHARACTER_IMAGE_URL` | 캐릭터를 내 그림으로 바꿀 때 이미지 주소 (`https://`로 시작, 누구나 볼 수 있는 주소) | 부엉이 선생님 |
| `NOTIFY_EMAIL` | 새 질문 알림 메일 받을 주소. `off` 면 알림 끔 | 스크립트 주인 계정 |
| `CHAT_WEBHOOK_URL` | 구글 챗 웹훅 주소. 넣으면 알림이 메일 대신 구글 챗으로 옴 ([아래](#구글-챗으로-알림-받기) 참고) | 없음 (메일로 알림) |
| `REFERENCE_ONLY` | `true` 면 `자료` 탭에 없는 질문엔 답하지 않음 | false (없으면 AI가 아는 내용으로 답함) |
| `AI_REPLY_TO_COMMENTS` | `false` 면 댓글에는 AI가 답하지 않음 | true |
| `TEACHER_NAMES` | 선생님이 댓글에 쓰는 이름 (쉼표로 여러 개). 이 이름의 댓글은 학생 분석에서 뺌 | 선생님 |
| `TEACHER_PASSWORD` | 학생 분석 화면 비밀번호. 비우면 분석 화면이 열리지 않음 | 없음 |
| `SYSTEM_PROMPT` | AI 답변 지침 (예: "너는 고등학교 정치 선생님이야…") | `Code.gs`의 `DEFAULT_SYSTEM_PROMPT` |

### 4. 처음 한 번 실행해서 권한 허용하기

1. 편집기 위쪽 함수 선택 칸에서 `setup` 을 고르고 **▶ 실행** 을 누릅니다.
2. 권한 요청 창이 뜨면 본인 계정을 고르고 허용합니다.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동** 을 누르면 됩니다. 내가 만든 스크립트라서 나오는 경고입니다.
3. 아래 실행 로그에 `Gemini 응답: 준비 완료` 비슷한 줄이 나오면 성공입니다. 시트에 `Posts`, `Comments` 탭도 생깁니다.

오류가 나면 로그 내용을 확인하세요.
- `GEMINI_API_KEY가 없습니다` → 3단계 속성 이름 철자를 확인하세요.
- `Gemini API 400` / `403` → 키가 잘못 복사됐거나 비활성화된 키입니다.
- `Gemini API 404` → `GEMINI_MODEL` 이름이 틀렸습니다. 속성을 지우면 기본 모델을 씁니다.
- `Gemini API 429` → 무료 호출 한도를 넘었습니다. 하루 한도는 한국 시간 오후 4~5시쯤 초기화됩니다. https://ai.dev/rate-limit 에서 남은 한도를 볼 수 있습니다.

### 5. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 유형 선택(⚙️)에서 **웹 앱** 을 고릅니다.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자** 로 설정하고 **배포** 합니다.
   (학교 구글 계정으로만 쓰게 하려면 "(학교 도메인) 내 모든 사용자"를 고르세요.)
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)이 게시판 주소입니다. 학생들에게 이 주소(또는 QR 코드)를 알려 주세요.

코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 를 해야 같은 주소에 반영됩니다.

### 6. (권장) 자동 재시도·자동 분류 켜기

Gemini 호출이 한도 초과 등으로 실패하면 카드에 "AI 답변을 받지 못했어요 · 다시 받기"가 보입니다.
버튼 대신 자동으로 다시 시도하게 하려면 편집기에서 `installRetryTrigger` 를 한 번 실행하세요. 10분마다 답변이 없는 글에 다시 답변을 시도하고, 과목·대단원·역량·인지적 수준 분류가 빠진 글도 5개씩 자동으로 채웁니다.

## 참고 자료로만 답하게 하기

1. 편집기에서 `setup` 을 한 번 실행하면 시트에 `자료` 탭이 생깁니다 (`과목 | 제목 | 내용`).
2. 한 줄에 자료 하나씩 붙여 넣습니다. 예: `경제 | 수요와 공급 | (교과서 단원 내용)`
   - `과목` 은 `사회와 문화 / 정치 / 경제 / 법과 사회` 중 하나로 쓰면, 그 과목 질문에만 그 자료를 씁니다. 비워 두면 모든 과목에 씁니다.
   - 셀 하나에 약 5만 자까지 들어갑니다. 한 번에 AI에게 보내는 자료는 6만 자까지입니다.
3. 자료에 답이 있으면 AI 튜터는 **자료 안의 내용으로만** 답합니다. 자료에 없으면 AI가 아는 내용으로 답합니다. 기본 개념이나 일반 지식이면 따로 안내하지 않고, 수업 범위 밖이거나 선생님 확인이 필요한 내용일 때만 "학교의 교과 담당 선생님께 한 번 더 여쭤봐도 좋아요"처럼 문맥에 맞게 한 문장 덧붙입니다. 같은 대화에서는 되풀이하지 않습니다.
   - 자료에 없는 질문에는 아예 답하지 않게 하려면 스크립트 속성 `REFERENCE_ONLY` 를 `true` 로 넣으세요.
4. 자료는 시트에서 고치면 다음 답변부터 바로 반영됩니다 (재배포 불필요).

## 관리

- **과목 분류**: 질문이 올라오면 AI가 답하면서 `사회와 문화 / 정치 / 경제 / 법과 사회` 중 하나로 분류하고, 게시판은 과목별 4칸으로 보입니다. 분류가 틀리면 `Posts` 탭의 `category` 칸을 직접 고치면 됩니다.
- **새 질문 알림**: 질문이 올라오면 AI 답변이 끝난 뒤 선생님 Gmail로 알림 메일이 갑니다. 처음 켤 때 편집기에서 `setup` 을 한 번 실행해 메일 보내기 권한을 허용하세요. 메일 대신 구글 챗으로 받을 수도 있습니다 (아래).
- **지난 달 질문**: 달이 바뀌면 지난 질문은 과목 칸마다 "2026년 10월" 같은 묶음으로 접히고, 누르면 펼쳐집니다.
- **이름으로 찾기**: 이름 목록에서 이름을 누르거나 검색칸에 입력하면 그 학생의 질문만 보입니다 (지난 달 묶음도 펼쳐짐).
- **이 기능 전에 올라온 글 분류**: 편집기에서 `analyzeExisting` 을 실행하면 과목·대단원·역량이 비어 있는 글을 AI가 나눠 줍니다. 무료 한도 때문에 한 번에 40개씩 천천히 처리하니, 실행 로그에 '남은 글'이 있으면 몇 분 뒤 다시 실행하세요.

- **글 지우기**: 시트 `Posts` 탭에서 그 줄을 삭제합니다. 댓글은 `Comments` 탭에서 지웁니다.
- **게시판 비우기**: 두 탭의 2번째 줄부터 모두 삭제합니다 (1번째 줄 제목은 남겨 두세요).
- **AI 말투·범위 바꾸기**: 스크립트 속성 `SYSTEM_PROMPT` 를 넣으면 다시 배포하지 않아도 바로 적용됩니다.
- 질문·댓글은 1000자, 이름은 30자까지 저장됩니다.

## 학생 분석 (선생님 전용)

질문이 올라오면 AI가 답하면서 **과목 · 대단원 · 사회과 교과 역량(0~2개) · 인지적 수준** 을 함께 분류해 `Posts` 탭의 `category`, `unit`, `competencies`, `level` 칸에 적습니다. 선생님 전용 화면에서 이것을 막대그래프로 볼 수 있습니다. 학생 게시판에는 보이지 않습니다.

1. 스크립트 속성에 `TEACHER_PASSWORD` 를 추가하고 비밀번호를 정해 넣습니다.
2. 게시판 오른쪽 위의 **🔒 교사 로그인** 버튼을 누르면 분석 페이지로 넘어가고, 비밀번호를 넣으면 바로 분석이 보입니다 (비밀번호를 넣어 둔 경우에만 보이고, 다시 배포해야 나타납니다). 게시판 주소 뒤에 `?teacher` 를 붙여 열어도 됩니다. 분석 페이지의 **← 질문 게시판** 버튼으로 돌아가고, **로그아웃** 을 누르면 다시 비밀번호를 물어봅니다. 로그인은 브라우저 창을 닫을 때까지 유지됩니다. 로그인한 동안에는 게시판의 버튼이 **📊 학생 분석** 으로 바뀌고, 옆의 **로그아웃** 으로 게시판에서도 로그아웃할 수 있습니다.
3. 비밀번호를 넣으면 분석 화면이 열립니다.

- **보기**: 학생 전체 또는 학생 한 명을 고릅니다. 학생 전체에서는 학생별 현황표가 나오고, 이름을 누르면 그 학생 분석으로 바뀝니다.
- **과목 · 기간**: 특정 과목이나 기간(예: 1학기)만 볼 수 있습니다.
- **그래프**: 질문 과목, 사회과 교과 역량, 인지적 수준, 과목별 대단원 비중. 막대를 누르면 아래 질문 목록이 그 항목으로 걸러집니다.
- **사회과 교과 역량**: 역량이 분명하게 드러난 질문에만 붙습니다. 용어 뜻·사실 확인·시험 범위처럼 단순한 질문은 `드러난 역량 없음`(시트에는 `없음`)으로 분류됩니다.
- **인지적 수준**: 질문이 요구하는 사고의 수준을 **지식 → 이해 → 적용 → 분석 → 종합 → 평가** 중 하나로 나눕니다. 위쪽 요약에 높은 수준(분석·종합·평가) 질문의 비율이 나오고, 학생별 현황표에 학생마다 주된 수준과 높은 수준 비율이 나옵니다.
- **학생 댓글**: 학생이 단 댓글도 사회과 교과 역량 분석에 들어갑니다. AI가 그 댓글에 답할 때 역량을 함께 분류하고(시트 `Comments` 탭의 `competencies` 칸), AI가 답하지 않은 댓글은 자동 재시도·`analyzeExisting` 이 채웁니다. 질문·댓글 목록에서 댓글은 원래 질문과 함께 보입니다. 선생님 댓글은 빼야 하니, 선생님이 댓글에 쓰는 이름을 스크립트 속성 `TEACHER_NAMES` 에 넣어 주세요 (쉼표로 여러 개, 기본값 `선생님`).
- 비밀번호를 10번 틀리면 10분 동안 잠깁니다.

**분석 기준 고치기**: `setup` 을 실행하면 시트에 `단원`(과목 | 대단원), `역량`(역량 | 설명) 탭이 기본값으로 생깁니다. 기본값은 2022 개정 교육과정을 참고한 예시라 **학교 교과서의 대단원 이름과 다를 수 있으니 꼭 확인해서 고쳐 주세요.** 고치면 다음 분류부터 바로 반영되고(재배포 불필요), 예전 글을 새 기준으로 다시 나누려면 `Posts` 탭의 `unit`·`competencies` 칸을 지우고 `analyzeExisting` 을 실행하세요. 역량의 `설명` 칸은 AI가 분류할 때 참고합니다.

**역량만 새 기준으로 다시 나누기**: 편집기에서 `reanalyzeCompetencies` 를 실행하면 모든 글의 역량을 지우고 다시 분류합니다 (한 번에 40개씩, 남은 글은 `analyzeExisting` 으로 이어서).

AI 분류는 틀릴 수 있습니다. 생활기록부 등에 쓸 때는 질문 원문을 직접 확인하세요. `Posts` 탭에서 칸을 직접 고칠 수 있습니다.

## 구글 챗으로 알림 받기

구글 챗 웹훅은 **학교·회사 구글 계정(Google Workspace)** 에서만 만들 수 있습니다. 게시판 스크립트는 지금 계정(일반 Gmail이어도 됨) 그대로 두고, 스페이스만 학교 계정으로 만들면 됩니다.

1. 학교 계정으로 https://chat.google.com 에 들어가 **새 채팅 → 스페이스 만들기** 로 스페이스를 하나 만듭니다 (예: "질문 알림"). 혼자 써도 됩니다.
2. 스페이스 이름 옆 **▼ → 앱 및 통합** → **웹훅 추가** 를 누릅니다.
   이 메뉴가 없으면 학교 관리자가 웹훅을 막아 둔 것입니다. 이때는 메일 알림을 그대로 쓰세요.
3. 이름(예: "질문 게시판")을 넣고 저장한 뒤, 나오는 웹훅 주소(`https://chat.googleapis.com/v1/spaces/...`)를 복사합니다.
4. Apps Script **프로젝트 설정 → 스크립트 속성** 에 `CHAT_WEBHOOK_URL` 을 추가하고 복사한 주소를 넣습니다.
5. 편집기에서 `testChatNotify` 를 골라 **▶ 실행** 합니다. 스페이스에 시험 메시지가 오면 끝입니다. (`Code.gs` 를 새로 붙여 넣었다면 **배포 → 배포 관리 → ✏️ → 새 버전** 으로 다시 배포하세요.)

- 웹훅 주소를 넣으면 **메일 알림은 멈춥니다.** 메일도 함께 받으려면 `NOTIFY_EMAIL` 에 메일 주소를 직접 넣으세요.
- 웹훅 주소를 아는 사람은 누구나 그 스페이스에 글을 올릴 수 있으니 다른 사람에게 공유하지 마세요.
- 휴대폰에 Google Chat 앱을 설치하고 학교 계정으로 로그인하면 푸시 알림으로 받을 수 있습니다.

## 자주 나오는 문제

- **웹 앱 주소를 열면 "현재 파일을 열 수 없습니다"** → 브라우저에 구글 계정이 여러 개 로그인돼 있을 때 나옵니다. 시크릿 창에서 열거나 계정을 하나만 남기세요.
- **"AI 답변을 받지 못했어요"만 나옴** → 편집기에서 `setup` 을 실행해 실행 로그의 오류를 확인하세요. `404 ... no longer available` 이면 모델이 바뀐 것이니, 오류가 알려 주는 모델 이름을 스크립트 속성 `GEMINI_MODEL` 에 넣으면 됩니다 (재배포 불필요).
