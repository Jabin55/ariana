# 화상 서버(LiveKit) 직접 운영하기 — Hetzner 해외 서버

LiveKit Cloud 대신 **월 정액 해외 서버 한 대**에 화상 서버를 직접 설치하는 방법입니다.
영상 데이터 요금이 거의 없어서, 사용량이 많아도 비용이 크게 늘지 않습니다.

- 서버: [Hetzner Cloud](https://www.hetzner.com/cloud) (독일·핀란드), **CX23 (2 vCPU·4GB·트래픽 월 20TB 포함)** 약 월 €6 = 연 약 10만 원
- 학교 전체(여러 반이 동시에 수업)라면 더 큰 서버로 바꾸면 됩니다 (아래 '서버 크기' 참고). 설치 방법은 같습니다.
- 한국에서 독일·핀란드까지 거리 때문에 영상·소리가 약 0.25~0.3초 늦습니다. 강의에는 거의 느껴지지 않고, 모둠 대화는 살짝 어색할 수 있습니다.

## 1. 서버 만들기 (약 10분, 명령어 입력 없음)

1. https://www.hetzner.com/cloud 에서 가입합니다. 결제 수단(카드·PayPal)을 등록하고, 신분 확인을 요청받으면 안내를 따릅니다.
2. **Cloud Console → 프로젝트 만들기 → Add Server(서버 추가)** 를 누르고 다음처럼 고릅니다.
   - Location(위치): **Helsinki** 또는 **Falkenstein** / **Nuremberg**
   - Image(운영체제): **Ubuntu 24.04**
   - Type(종류): **Shared vCPU → CX23** (안 보이면 CX33 또는 CAX11 등 비슷한 값싼 것)
   - Networking: **Public IPv4** 켜기 (학생 기기 대부분이 IPv4로 접속)
   - SSH keys: 건너뛰어도 됩니다 (root 비밀번호가 메일로 옵니다)
   - **Cloud config** 칸: 이 폴더의 [`cloud-init.yaml`](cloud-init.yaml) 내용을 **전부 복사해 붙여 넣기**
   - Name: `live-class` 같은 이름
3. **Create & Buy now** 를 누릅니다. 서버가 켜지면 자동으로 설치가 진행됩니다(약 3~5분).

## 2. 접속 정보 받아서 Render에 넣기

1. 서버 화면 오른쪽 위 **>_ (Console)** 버튼을 누르고, `root` 와 메일로 받은 비밀번호로 로그인합니다
   (처음 로그인하면 비밀번호를 바꾸라고 합니다).
2. 로그인하면 화면에 바로 이런 접속 정보가 보입니다. 안 보이면 `cat /root/livekit-info.txt` 를 입력하세요.
   ```
   LIVEKIT_URL=wss://live.49-12-34-56.sslip.io
   LIVEKIT_API_KEY=API…
   LIVEKIT_API_SECRET=…
   ```
   아직 안 생겼으면 설치가 진행 중인 것이니 1~2분 뒤 다시 확인하세요. 진행 상황: `tail -f /root/setup.log`
3. Render → 서비스 → **Environment** 에서 세 값을 넣고 저장합니다. Render가 자동으로 다시 시작합니다.
4. 브라우저로 `https://live.…sslip.io` 를 열어 **OK** 가 보이면 정상입니다.

> 주소의 `sslip.io` 는 IP 주소만으로 쓰는 **무료 주소**입니다. 학교 도메인(예: `live.myschool.kr`)을 쓰고 싶으면
> DNS에 `live.myschool.kr` 와 `turn.live.myschool.kr` 두 이름을 서버 IP로 등록한 뒤, 콘솔에서
> `bash /root/setup.sh live.myschool.kr` 를 실행하고 바뀐 `LIVEKIT_URL` 을 Render에 넣으세요(키는 그대로).

## 3. 관리 — 평소에는 할 일이 없습니다

| 상황 | 누가 하나 |
|---|---|
| 서버가 재부팅되거나 프로그램이 멈춤 | 자동으로 다시 켜짐 |
| HTTPS 인증서 갱신 (90일마다) | 자동 |
| 운영체제 보안 업데이트 | 매일 자동 설치, 필요하면 **새벽 4시(한국 시각)** 자동 재부팅 |
| 서버 하드웨어 고장 | Hetzner가 다른 기계로 옮김 |
| 학생 정보 백업 | 필요 없음 — 화상 서버에는 아무것도 저장하지 않음 (회원·출결은 Render·Neon에 있음) |

가끔 할 일:
- **결제 카드 유효기간** 확인 (Hetzner가 매달 카드로 청구, 인보이스 PDF는 콘솔에서 내려받아 학교에 청구)
- 학교 도메인을 쓰면 **1년마다 도메인 갱신**
- 권장: [UptimeRobot](https://uptimerobot.com)(무료)에 `https://live.…sslip.io` 를 등록해 두면 서버가 멈췄을 때 메일로 알려 줍니다.

문제가 생기면:
1. Hetzner 콘솔에서 서버 **Power → Reset**(재시작). 대부분 이것으로 해결됩니다.
2. 그래도 안 되면 콘솔에 로그인해 `cd /opt/livekit && docker compose logs --tail 50` 로 오류를 확인하세요.
3. 최후의 방법: 서버를 지우고 1번부터 다시 만들기(10분). 이때는 키가 바뀌므로 Render 값을 다시 넣어야 합니다.

선택 사항 — LiveKit 새 버전으로 올리기(1년에 한두 번이면 충분, 안 해도 동작):
`setup.sh` 맨 위 `LIVEKIT_IMAGE` 버전을 바꾸고 `bash /root/setup.sh` 를 다시 실행합니다.

## 서버 크기

화상 서버는 받는 영상을 다른 사람들에게 나눠 주는 일만 해서 CPU를 많이 쓰지 않습니다(데이터 절약 모드 기준).

| 동시에 수업하는 규모 | 권장 서버 | 월 비용 (2026년 6월 가격 인상 반영, 바뀔 수 있음) |
|---|---|---|
| 한 반 (~40명) | CX23 (2 vCPU, 트래픽 20TB) | 약 €6 |
| 몇 반 동시 (~200명) | CX33 또는 CX43 | 약 €8~16 |
| 학교 전체 (~1,000명 동시) | CX53 (16 vCPU, 20TB) 또는 전용 서버 AX41 (트래픽 무제한) | 약 €30~60 |

- 서버를 바꾸려면 콘솔에서 **Rescale** 로 크기만 올리면 됩니다(설치 다시 할 필요 없음, 1~2분 꺼짐).
- 클라우드 서버의 포함 트래픽(20TB)을 넘으면 1TB당 약 €1이 붙습니다. 데이터 절약 모드를 켜면 한 반 월 5회×4시간은 약 0.2TB입니다.

## 열리는 포트 (참고)

| 포트 | 용도 |
|---|---|
| 443/tcp | 화상 서버 접속(HTTPS) + 학교·공공 와이파이에서 UDP가 막혔을 때 우회(TURN/TLS) |
| 80/tcp | HTTPS 인증서 발급 |
| 7881/tcp | UDP가 안 될 때 영상 전송 |
| 3478/udp, 50000–60000/udp | 영상·음성 (가장 빠른 경로) |
